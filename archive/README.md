# Protótipos anteriores

Este diretório preserva versões antigas da interface. A aplicação atual usa
`frontend/`, servido pelo Flask com `python run.py` na raiz do repositório.

| Diretório | Origem | Estado |
|---|---|---|
| `static/` | `index.html`, `app.js` e `style.css` da raiz | Primeiro protótipo estático. |
| `react-root/` | Antigo `verificai-react/` | Protótipo React/Vite. |
| `react-frontend/` | Antigo `frontend/verificai-react/` | Outra revisão do protótipo React/Vite. |

As duas revisões React têm diferenças e foram preservadas. Não são os pontos
de entrada suportados para testar o ensemble atual. Não é necessário instalar
Node.js para executar a aplicação Flask.
